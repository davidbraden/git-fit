# AI tickets

One short Markdown file per AI work session. Write it before committing the
session's changes; keep it to one page and link it from the commit message when
useful (for example, `AI-002`).

Use sequential filenames: `AI-001-short-title.md`.

```md
# AI-00N — Short title

## Asked
- What the user asked for.

## Decisions
- Important choices and why.

## Changed
- Files or behaviour changed.
```

Write the outcome, not a raw chat transcript. Keep bullets concrete and omit
sections that genuinely do not apply.

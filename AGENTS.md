# AI session tickets

For every completed AI work session or commit, add a concise, one-page record
to `.ai/tickets/` before committing.

- Read `.ai/tickets/README.md` for the filename convention and template.
- Use the next sequential `AI-###` identifier.
- Summarise the request, key decisions, and changes made; do not paste a raw
  chat transcript.
- Do not edit previous tickets except to correct a factual error.
